# Один выстрел

Кинематографичная 3D-сцена в браузере (~60 секунд): снайпер в маскхалате на закате, рентген спускового механизма,
выстрел в сверхзамедленной съёмке, полёт пули над долиной и яблоко, разлетающееся на куски на пне в 300 метрах.

Всё генерируется кодом — модели, текстуры и звук. Внешних ассетов нет.

## Запуск

```bash
pnpm install
pnpm dev        # http://localhost:5173
pnpm build      # статическая сборка в dist/
pnpm preview    # раздача dist/
```

`dist/` — обычный статический сайт, его можно выложить на любой хостинг (GitHub Pages, Netlify, Vercel, S3).

## Управление

- **▶ Смотреть** — старт со звуком (браузеры запускают звук только после клика)
- **Space** — пауза, **M** — звук, **R** — заново
- `?q=low` — облегчённая версия для слабых компьютеров (меньше травы, без MSAA)
- `?t=38` — перемотать к нужной секунде (для отладки)

## Сцена по планам

| Время | План |
| --- | --- |
| 0–5.5 с | Яблоко на пне в закатном свете |
| 5.5–11.5 с | Кран-проезд над снайпером в маскхалате, титр |
| 11.5–15.5 с | Детали винтовки, щелчки барабанчика прицела |
| 15.5–22.5 с | Вид в прицел: дыхание, сердцебиение, задержка дыхания |
| 22.5–28.5 с | Рентген: палец жмёт спуск, шептало, боёк, капсюль, порох, пуля в нарезах |
| 28.5–32 с | Выход пули из дульного тормоза: вспышка, ударная волна, пороховые газы |
| 32–37.5 с | Камера летит за пулей над долиной |
| 37.5–42.5 с | Рентген яблока: пуля входит, ударная волна внутри |
| 42.5–50 с | Яблоко разлетается в замедлении, потом время резко возвращается |
| 50–61 с | Перезарядка с выбросом гильзы, финальный титр |

## Устройство

- `src/director.js` — таймлайн: планы камеры, масштаб времени (slow-mo), звуковые события
- `src/world.js` — рельеф, небо, трава с ветром, деревья, пень
- `src/rifle.js`, `src/sniper.js`, `src/bullet.js`, `src/apple.js` — процедурные модели, рентген-внутренности, физика разлёта
- `src/effects.js` — дым, вспышка, пыль, гильза, частицы
- `src/xray.js`, `src/post.js` — рентген-материалы и пост-обработка (bloom, грейдинг, зум-блюр, зерно)
- `src/audio.js` — синтез звука на Web Audio: ветер, птицы, дрон, сердцебиение, выстрел, свист пули, взрыв

Стек: [three.js](https://threejs.org/) r187, Vite.
